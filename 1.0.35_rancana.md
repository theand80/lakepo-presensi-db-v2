# Rencana 1.0.35: Perbaiki Invalid Cell Coordinate 'AB' & Tambah Test File Nyata

## A. Root Cause
- `app/Exports/downloadPresensiRekapByKantorExcelExport.php:169`
  - `'A3:'.$highestColumn` → `A3:AB` (invalid) → `Coordinate::coordinateFromString('AB')` gagal
- Keys lain valid: `3` → `A3:AB3`, `'A'/'C'/'E:AB'` dikonversi jadi whole-column (`A1:A1048576`) → jalur COLUMN efisien
- Crash tidak ter-catch oleh `Excel::fake()` karena writer tidak dijalankan

## B. Perbaikan Code
**File:** `app/Exports/downloadPresensiRekapByKantorExcelExport.php`

Ubah pada `styles()`:
- Ganti `'A3:'.$highestColumn` → `'A:'.$highestColumn` (range valid, path COLUMN)
- Ganti hardcode `$highestColumn = 'AB'` → `$sheet->getHighestColumn()` agar konsisten
- Sisanya dibiarkan

## C. Perbaikan Test
**File:** `tests/Feature/RekapSatuKantorTest.php`

- Pertahankan test berbasis `Excel::fake()` untuk intent (nama file + kelas export)
- Tambah test "real file": POST route download **tanpa** `Excel::fake()` → `assertOk()` + `assertDownload($filename)`
- Baca file dari `$response->baseResponse->getFile()->getPathname()`, salin ke temp `.xlsx`, muat via `PhpOffice\PhpSpreadsheet\IOFactory`
- Assert: A1 = nama kantor, A2 = `Periode bulan 08 tahun YYYY`, baris 3 = 28 judul, baris 4 = data (NIP, nama, F4=hadir, AB4=`95%`)
- Bersihkan temp file
