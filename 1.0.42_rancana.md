# Rencana 1.0.42 — Otorisasi Spatie (Admin, PIC, Operator) + Halaman Pendukung

## Model Otorisasi

Kunci kantor = **`unor_siasn_induk`** (dari `asn_dari_apis`), konsisten dengan query rekap `PicController`.

| Role | Akses route | Sumber daftar kantor yang boleh diakses |
|---|---|---|
| **Admin** | Semua `/admin/*` + `/pic/*` | Semua kantor (tanpa filter) |
| **PIC** | `/pic/*` | Daftar di pivot `user_unor` (diset admin); jika kosong → fallback `users.unor` |
| **Operator** | `/pic/*` | Daftar di pivot `user_unor` (diset admin); jika kosong → terkunci `users.unor` sendiri |

## A. Inti Otorisasi

1. **Migrasi `user_unor`** — ubah kolom jadi `user_id` + string `unor_siasn_induk` (unique pair). Tabel lama kosong & belum dipakai → aman.
2. **`RoleSeeder`** — role `admin`/`pic`/`operator` + migrasi kolom legacy `users.role` → Spatie; daftar di `DatabaseSeeder`.
3. **`User` model** — relasi `kantorUnor()` (belongsToMany via `user_unor` / `unor_siasn_induk`) + `kantorNames()`:
   - admin → `null` (semua kantor)
   - selain admin → daftar `user_unor`; jika kosong → fallback `[users.unor]`
4. **`routes/web.php`** — `/admin/*` → `auth` + `role:admin`; `/pic/*` → `auth` + `role:pic|operator|admin`; `/logout`, `/dashboard` → `auth`.
5. **`AuthController`** — redirect login per role: admin → `/admin`, pic/operator → `/pic/dashboard/pic`.
6. **`PicController`** — filter `$listKantor` & validasi `filterNamaKantor` dengan `kantorNames()` (index, lihatSatuKantorSaja, export Excel/PDF, bpk); admin tanpa filter.
7. **`sidenav.blade.php`** — `@role` per section (Admin, PIC, Operator) + perbaiki link mati ke route asli.
8. Kolom `users.role` — berhenti dipakai, tidak dihapus.

## B. Halaman Baru

### B1. Halaman Edit User
- Route (grup `role:admin`): `GET /admin/edit-user/{id}`, `PUT /admin/update-user/{id}`.
- View baru `resources/views/admin/user/editUser.blade.php`: NIP & Nama read-only, Unor select, Password opsional, Akses (admin/pic/operator), multi-select "Kantor yang Boleh Diakses" (`unor_siasn_induk[]`) untuk PIC/Operator (sembunyi untuk admin), opsi kosongkan.
- `UserController::edit/update`: `assignRole`/`syncRoles`, `sync()` pivot; cegah self-demotion admin.

### B2. Form Tambah User Diperbarui
- `listUser.blade.php`: field multi-select kantor (tampil saat akses = PIC/Operator, JS toggle), sinkron ke `user_unor` di `store()`. Tabel: role dari `getRoleNames()`, tampilkan kantor.

### B3. Tidak Dibuat
- Halaman `/operator/*` — Operator memakai `/pic/*` dengan data di-scope.
- Dashboard khusus per role — `/dashboard` generik untuk semua role.
