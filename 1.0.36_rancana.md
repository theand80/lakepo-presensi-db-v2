# Rencana 1.0.36: Tombol Download PDF (rekap presensi by kantor)

## Kondisi Saat Ini
- Tombol PDF di `resources/views/pic/rekapSatuKantorSiasnSaja.blade.php` (baris 190-196): form `action=""` tanpa hidden input `namaKantor` dan `month` → tidak berfungsi.
- Tidak ada dependency PDF terpasang (dompdf/mpdf/tcpdf hanya suggest PhpSpreadsheet). barryvdh/laravel-dompdf v3.1.2 cocok (Laravel 13, PHP 8.3).
- Kertas F4 landscape (330 mm × 215 mm) → diatur via `@page { size: 330mm 215mm; }` di view dan `setPaper([0,0,935.43,609.45], 'portrait')` di controller (935.43pt = 330/25.4*72, 609.45pt = 215/25.4*72).

## Target
Menambah route, controller method, view PDF terpisah (tanpa x-layout/Tailwind), memperbaiki tombol PDF, menambah test, dan meng-install barryvdh/laravel-dompdf.

## Langkah Eksekusi

1. **Rencana** — file ini (`1.0.36_rancana.md`) telah disimpan.
2. **Dependency** — `composer require barryvdh/laravel-dompdf` (v3.x). Tidak publish config.
3. **Route** — tambah di `routes/web.php` setelah baris 58:
   `Route::post('/pic/download-presensi-by-kantor-pdf', [PicController::class, 'downloadPresensiRekapByKantorPdf']);`
4. **Controller (PicController)** — tambahkan method `downloadPresensiRekapByKantorPdf(Request $request)`:
   - Validasi: `namaKantor` required|string, `month` required|date
   - Ekstrak `$bln = substr($month,5,2)`, `$thn = substr($month,0,4)`, `$opd = $request->input('namaKantor','')`
   - `$filename = 'kehadiran ASN bulan '.$bln.' tahun '.$thn.' di '.str_replace('/','-',$opd).'.pdf'`
   - `$data = $this->__rekapSatuKantor($opd, $month)`
   - `PDF::loadView('pic.pdf.rekapSatuKantor', compact('data','opd','month','bln','thn'))->setPaper([0,0,935.43,609.45],'portrait')->download($filename)`
5. **View PDF baru** — `resources/views/pic/pdf/rekapSatuKantor.blade.php` (standalone HTML, CSS inline):

   - Empty state "Tidak ada data."
6. **Perbaiki tombol PDF** — `rekapSatuKantorSiasnSaja.blade.php:190-196`:

   - tambah hidden `name="namaKantor" value="{{ $selectedKantor }}"`, `name="month" value="{{ $selectedMonth }}"`
