# 1.0.43 — Quick-Set Role & Kantor di List User

Konteks: halaman `/admin/list-user` sudah punya tabel dengan kolom ringkasan role + kantor (dari pekerjaan sebelumnya). Yang perlu ditambah: **pencarian & filter role**, **modal quick-set** (ganti role + atur multi-kantor tanpa buka halaman edit), dan **blokir self-edit**.

## 1. Backend

### `UserController::index()` — tambah pencarian & filter
- Terima query param `q` (cari NIP/nama) dan `role` (filter admin/pic/operator).
- `User::query()->with('roles')` → `when($q, ...)` where nip/nama like, `when($role, ...)` whereHas roles.
- Kirim `$filterQ`, `$filterRole` ke view agar nilai filter tetap terisi.

### Method baru `quickSetRole(Request, string $id)` — PUT
- Validasi: `akses` required in:admin,pic,operator; `kantors` nullable array of string.
- **Blokir self-edit**: jika `$user->id === auth()->id()` → redirect back `error` (tidak ubah apa pun).
- `syncRoles([$akses])`; jika admin → `syncKantorUnor([])`, else `syncKantorUnor(kantors)`.
- Redirect back `success`.

### Route (dalam grup `role:admin` yang sudah ada)
- `PUT /admin/quick-set-role/{id}` → `UserController::quickSetRole`.

## 2. View — `listUser.blade.php`

### a. Bilah pencarian & filter (di atas tabel)
- Form GET ke `/admin/list-user`: input `q` (placeholder "Cari NIP / nama"), select `role` (Semua/Admin/Pic/Operator), tombol "Filter" + link "Reset".

### b. Tombol "Atur" di kolom Aksi
- Tombol `Atur` (hijau) di samping Edit & Hapus, membawa `data-user-id`, `data-user-nama`, `data-role`, `data-kantors` (daftar dipisah koma).
- Untuk baris akun sendiri (id == auth id), tombol Atur disembunyikan/di-disable.

### c. Modal quick-set (satu modal reusable, dipopulasi JS)
- Form POST `@method('PUT')` ke `/admin/quick-set-role/{id}` (action diisi JS).
- Isi: judul "Atur Role & Kantor", nama+NIP user (read-only), select role, multi-select kantor (`kantors[]`) yang tampil hanya saat role = pic/operator, tombol Simpan + Batal.
- JS: klik Atur → isi field + set action form + tampilkan modal; ganti role → toggle wrapper kantor; tutup via X / klik backdrop.

### d. Kolom ringkasan
- Sudah ada (Role badge + Kantor Akses). Tidak perlu diubah besar-besaran; pastikan filter `q`/`role` tidak merusaknya.
