# Rencana Implementasi: Hitung TAS (Tidak Absen Siang) + Total Hari TAS

## Konteks / Temuan

- Kolom TAS sudah ada di tabel (view `rekapSatuKantorSiasnSaja.blade.php:222`, `rekap.blade.php:220`), Excel (`downloadPresensiRekapByKantorExcelExport.php:96`), dan PDF (`pdf/rekapSatuKantor.blade.php:158`), tapi nilainya selalu 0 karena penghitungan di `PicController::__dataYangDitampilkan` (baris 253–265) hanya membaca kode `status_change ?: status_script`, dan generator `status_script` di `DataAbsenController::__nilaiStatusScript` tidak pernah menghasilkan `TAS`. Data 2026-09: `status_script='TAS'` = 0, `status_change='TAS'` = 0.
- "Siang" di aplikasi ini = `checkRest` (lihat `detail_RekapByNip.blade.php`: `jam_siang` → `checkRest_time`).
- Definisi TAS dari Anda: `checkIn` ATAU `checkOut` ada, tapi `checkRest` kosong.

## 1. Perbaiki logika hitung TAS per NIP (sumber data bersama)

**File:** `app/Http/Controllers/PicController.php` — `__dataYangDitampilkan()` (sekitar baris 252–265)

Di dalam loop `foreach ($group as $record)`, setelah baris skip `TK`+`hari_libur` dan `LN`, tambahkan hitungan TAS terpisah dari loop kode status:

- Ambil nilai efektif (pakai `_change` jika ada, selain itu value asli):
  - `$pagi = checkIn_time_with_timezone_change ?: checkIn_time_with_timezone`
  - `$siang = checkRest_time_with_timezone_change ?: checkRest_time_with_timezone`
  - `$sore = checkOut_time_with_timezone_change ?: checkOut_time_with_timezone`
- Jika (`$pagi` terisi ATAU `$sore` terisi) DAN `$siang` kosong → `$rekap['rekap']['TAS']++`
- Hapus ketergantungan TAS pada loop `$st` (biarkan loop `$st` tetap untuk kode lain). Jika status manual `TAS` ada di `status_change`, tetap dihitung via aturan waktu sesuai definisi.

Karena `__dataYangDitampilkan` dipakai oleh:
- `lihatSatuKantorSaja` (halaman rekap kantor)
- `index` / `__rekapSatuKantor` → halaman `pic/rekap`
- `downloadPresensiRekapByKantorExcel`
- `downloadPresensiRekapByKantorPdf`

maka kolom TAS di semua tempat ikut benar.

## 2. Total hari TAS di halaman rekap kantor

**File:** `app/Http/Controllers/PicController.php` — `lihatSatuKantorSaja()` (baris 88–101)

- Setelah `$data = $this->__rekapSatuKantor(...)`, hitung `$totalTas = collect($data)->sum(fn($item) => $item['rekap']['TAS'] ?? 0)`
- Pass ke view: `compact('data', 'listKantor', 'selectedMonth', 'selectedKantor', 'totalTas')`

**File:** `resources/views/pic/rekapSatuKantorSiasnSaja.blade.php`

- Di bagian Ringkasan Kehadiran (grid kartu): tambahkan kartu baru "Tidak Absen Siang (TAS)" menampilkan `$totalTas` + label "hari" — tanpa menghapus kartu placeholder lain.
- Di footer tabel: tambahkan baris "Total" di `tfoot` yang menjumlahkan kolom TAS saja, sisanya `-`.
